Помощь (руководство пользователя)

Краткая инструкция по работе с интернет‑магазином «ТехноМаркет».

1) Поиск и выбор товара

  1. Откройте страницу Каталог.
  2. Используйте фильтры: категория, цена, бренд, ключевые характеристики.
  3. Для быстрого поиска используйте строку поиска в шапке сайта.
  4. Нажмите «Подробнее», чтобы открыть карточку товара.

2) Корзина

  1. Нажмите «В корзину» в каталоге или в карточке товара.
  2. Откройте Корзину — там можно изменить количество или удалить товар.
  3. Проверьте итоговую сумму и нажмите «Оформить заказ».

3) Оформление заказа

  1. Заполните ФИО, телефон, email.
  2. Выберите способ доставки: самовывоз / курьером / транспортной компанией.
  3. При необходимости добавьте комментарий.
  4. Нажмите «Подтвердить заказ». Номер заказа появится на экране.

4) Личный кабинет

  1. Откройте Личный кабинет.
  2. Если аккаунта нет — зарегистрируйтесь (email/телефон + пароль).
  3. После входа отображается история заказов и их статусы.
  4. Если забыли пароль — используйте восстановление (в демо токен показывается на экране).
Важно про демо‑версию. В этой MVP‑реализации данные пользователя, корзина и заказы сохраняются в браузере (localStorage). В промышленной версии хранение должно быть серверным с соблюдением 152‑ФЗ.
Юридические документы Для соответствия 152‑ФЗ и требованиям магазина предусмотрены страницы‑заглушки: Политика ПДн, Пользовательское соглашение, Правила продажи.
